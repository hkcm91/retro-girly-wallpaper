In Lively, use Library → right-click wallpaper → Customise for reliable persistent controls. Browser and Lively settings are separate.

♡　a little help

Select a calendar day to write a note. Saving an empty note deletes it. Personalise changes your colors, labels, background and sound.

The three zones are visual guides, not folders. Windows still manages your desktop files and icons.

In Lively, mouse input depends on its interaction settings and the desktop. Real icons and other windows can cover wallpaper controls. Keyboard input is off by default; enabling it can hide desktop icons.

Use Lively’s Customise panel for labels and appearance. For typing notes or choosing files, the browser preview is the easiest option. It has separate local storage; export/import can transfer your settings when file selection is available.

Sound is a quiet click chime, off by default. Browsers may require a click before audio plays. Reduced-motion preferences are respected.

Our host was compiled as a Windows x64 EXE with the Windows Framework compiler.
The native test creates a real Explorer-background child window and exercises
our own renderer and IPC. It then removes its wallpaper window and exits.
It did not change the static Windows wallpaper or install startup entries.
The native renderer was visually reviewed at its actual 1600x900 viewport.

Limits: verified on this single-display Windows 10 setup only. Other Windows
versions, multiple monitors, Explorer restart recovery and sleep/resume still
need testing. WorkerW is an undocumented Explorer convention. No direct
desktop-input forwarding, start-at-login setting or automatic fullscreen/
battery pause policy is implemented. Editing is through our own app window.
Audio is optional editor click feedback; audible output was not measured.

WebView2 is Microsoft's shared renderer, not a third-party wallpaper host.
The app needs WebView2 Runtime and .NET Framework 4.8 installed. No Lively
dependency remains in this desktop build. Our code and artwork are MIT;
Microsoft SDK binary license and notice files accompany the app.

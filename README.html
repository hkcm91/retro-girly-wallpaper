PETAL OS / DESKTOP PROTOTYPE 0.2

Our own little desktop.

Petal OS is a standalone Windows wallpaper application with a pastel four-panel design. Its own desktop host places the wallpaper behind your icons, and its own editor controls it live. Lively is not required.

Download the Windows app · Source repository · Browser preview

Run the Windows app

  1. Download and extract Petal-OS-Desktop.zip into a permanent folder. Keep all files together.
  2. Run PetalOS.exe. It opens Desktop Studio, our editor window.
  3. Select a display or All displays, then click Apply wallpaper.
  4. Use Personalise for theme, colors, four zone labels, background image, animation, sound and clock format. Edit calendar notes in the editor. Changes appear live on the wallpaper.
  5. Closing the editor keeps the wallpaper running. Double-click the Petal OS tray icon to reopen it.
  6. Stop wallpaper removes our wallpaper and shows your usual background. Exit Petal OS stops it and closes the application.

This is a portable Windows x64 prototype. It uses .NET Framework 4.8 and Microsoft Edge WebView2, rather than a separate wallpaper application. If WebView2 is missing, install Microsoft's Evergreen Runtime. Both prerequisites are present on the PC used for testing. No administrator privileges, startup entry or installer is required. This build is unsigned; Windows download reputation prompts may appear. Source and build instructions are included.

Desktop interaction

The wallpaper lives behind Windows icons. In this prototype, use the Petal OS editor window to interact with the calendar, type notes, choose files and adjust appearance. We do not capture global mouse or keyboard input or turn off desktop icons. The zones are visual guides for your real Windows shortcuts, not folders or file managers.

For free icon placement, right-click the Windows desktop → View → turn off Auto arrange icons, then position shortcuts inside the four panels. Layout changes with resolution and display scaling, so Windows icons may need repositioning.

What is included

  • Our own native Windows host, tray controls, display selector, Apply / Stop / Exit and editor.
  • Four equal shortcut zones in a 2×2 grid, with editable labels.
  • Live local clock and date; calendar with local notes.
  • Pixel hearts, sparkles and bow; reduced-motion support and animation switch.
  • Rose, lavender and mint palettes, an accent picker, built-in background styles and your own PNG/JPG/WebP images up to 2 MB.
  • Optional soft click sounds in the editor, off by default.
  • Settings export/import, including notes and uploaded image.
  • Eight original matching icons in Windows ICO, PNG and SVG formats.

Settings and offline use

The desktop app saves settings and calendar notes to %LocalAppData%\PetalOS\settings.json. Its WebView2 profile and diagnostic log live in the same PetalOS folder. The app runs locally without a server or internet once its prerequisites are installed. No account or API key is used. Export settings for a backup; exports contain your notes and image.

The GitHub Pages version is a browser preview and cannot set the Windows wallpaper by itself. Its browser storage is separate from the Windows app. Export from the preview and import in Desktop Studio to transfer your settings. The browser-only offline ZIP can also be extracted and opened with index.html.

Matching icons

Keep ICO files in a permanent folder. For shortcuts, right-click → Properties → Shortcut → Change Icon → Browse. For folders, Properties → Customize → Change Icon. For This PC or Recycle Bin, Windows Settings → Personalization → Themes → Desktop icon settings. Exact labels vary by Windows version.

Prototype limits and verification

The native app was tested on this Windows 10 x64 PC with WebView2 155. The test initialized our EXE, rendered the four-panel page, attached its visible wallpaper window to Explorer's background layer, sent an editor change live to the wallpaper, saved settings on disk, then removed the wallpaper window on Stop.

Explorer's background window arrangement is not a documented wallpaper hosting contract. Windows 11, third-party desktop customizations, Explorer restarts, multiple-monitor arrangements and sleep/resume still need wider testing. If attachment fails, Petal OS stops the wallpaper and keeps the editor available. No automatic start at login or fullscreen/battery pause policy is implemented in this prototype.

Develop or host the preview

The native source is in the repository's desktop/ folder. Run its build.ps1 on Windows; it compiles the host with the Windows .NET Framework compiler and obtains the pinned Microsoft WebView2 SDK if needed. The complete source ZIP includes web assets. The compiled app does not need build tools.

GitHub Pages publishes main → /(root). The static HTML/CSS/JS preview remains buildless; publishing a website is separate from running our desktop app. There are no remote fonts, CDNs or online APIs in the wallpaper.

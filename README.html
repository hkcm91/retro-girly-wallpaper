A little space to bloom.

Your Retro Girly interactive wallpaper: a live clock, calendar with local notes, pixel hearts and bows, three editable shortcut zones, three palettes, four built-in background styles and your own images.

Try it offline

  1. Extract the entire ZIP into a permanent folder, for example Documents\Wallpapers\PetalOS.
  2. Double-click index.html to open it in Edge or Chrome. No build, server, account, API key, or internet connection is needed.
  3. Select Personalise to change your palette, accent, background, labels, clock format and motion. Optional sound is a soft click chime, initially off.
  4. Select a calendar day, enter a note, then Save. A dot marks a saved note. Save an empty note to delete it. Today returns to the current month and date.

Settings save locally when the browser/player allows storage. Export settings backs up appearance, notes and uploaded image as JSON. Import restores that file. Appearance reset keeps notes. The local file, GitHub Pages, and Lively each have separate storage; they do not sync. Private browsing, browser cleanup, moving the file, or player changes can remove or isolate saved settings. Use exports for important notes. This is a lightweight note calendar, without reminders, accounts or cloud sync.

Install in Lively Wallpaper

  1. Install Lively from its official website.
  2. Open Lively and choose Add Wallpaper. Select or drag in the provided Petal-OS-Lively.zip. This ZIP has LivelyInfo.json at its root.
  3. If ZIP import fails on your version, extract the offline package into a permanent folder, then use Add Wallpaper → Choose a file → select index.html. Keep that whole folder in place; Lively may reference it rather than copy it.
  4. Choose your display and apply the wallpaper. A separate display arrangement may have separate settings.
  5. In the Lively library, right-click this wallpaper → Customise. Change zone labels, palette, accent, background, motion, sound, clock format, note editor visibility and volume there.

For a custom background in Lively, select an image in the Custom background image control, then select Background → Custom image. The package includes a sample rose gingham PNG. If your version does not show a file picker, add PNG/JPG/WebP files directly to the wallpaper’s backgrounds folder and reopen Customise. Palette and accent are separate controls in Lively: choose an accent too if you want it to match the palette.

What’s verified: browser behavior and the Lively property callback contract. Actual Lively ZIP import, desktop input routing, sound output and multi-monitor playback still need a check on your Lively installation. See the included report.

Mouse and keyboard limitations

Lively renders this webpage behind the Windows desktop. It does not turn the zones into real folders or give the webpage permission to move files, launch installed apps, or replace Explorer. Real Windows icons sit above it and can cover controls.

  • The official Lively guide says mouse input is enabled by default. Check Settings → Wallpaper → Interaction → Wallpaper Input if clicks do not reach the wallpaper. Exact labels can vary by version.
  • Test clicks on exposed wallpaper with other windows minimized and desktop icons away from the calendar and buttons. Mouse handling, drag selection, focus and file/color pickers can differ from an ordinary browser. A browser test cannot prove desktop click routing.
  • Keyboard input is off by default. Lively offers a Keyboard input mode; its documentation says enabling keyboard input hides desktop icons to avoid accidental selection. Restore icon visibility through the desktop’s View → Show desktop icons if needed.
  • For reliable label and appearance editing, use Lively Customise. It saves settings on disk and sends them to the wallpaper at launch. It does not require typing directly onto the wallpaper.
  • For calendar notes, browser editing is the easiest route. Transferring an export to the wallpaper requires a working Import file picker in that player. Otherwise keep notes in the browser; do not assume a browser edit changes Lively.
  • Browser Personalise controls are not written back into Lively’s Customise settings. At the next launch, Lively’s saved properties take precedence for matching controls.
  • Sound needs an initial wallpaper click or other audio-unlocking user gesture and unmuted player/system output. It is a click chime, not background music. Reduced-motion system preferences override decorative animation even when the motion toggle is on.

Official references: Lively interaction and properties; Lively input and file-location troubleshooting.

Arrange the shortcut zones

On the Windows desktop, right-click empty space → View → turn off Auto arrange icons if you want free placement. Drag your real shortcuts into the three outlined areas. The wallpaper does not detect or manage them. The layout adjusts for screen size, so icon placement may need adjustment after changing resolution, scaling or display arrangement. The clock and calendar sit on the left; leave those controls clear.

Matching PC icon starter pack

The icons folder contains eight original designs in multi-resolution .ico, transparent 256px PNG and editable SVG. ICO files include 16, 24, 32, 48, 64, 128 and 256px versions.

  • Shortcut: right-click → Properties → Shortcut → Change Icon → Browse → choose an ICO.
  • Folder: right-click → Properties → Customize → Change Icon → Browse.
  • This PC / Recycle Bin: Windows Settings → Personalization → Themes → Desktop icon settings → select icon → Change Icon. Menu wording varies by Windows version.

Keep the icons in a permanent location; Windows references their paths. Changing icons is manual. No registry changes, installers, executables or automatic system modifications are included.

Publish the preview on GitHub Pages

The public preview is published at hkcm91.github.io/retro-girly-wallpaper. Source files and downloadable packages are in hkcm91/retro-girly-wallpaper. The steps below explain how to redeploy it or host your own copy.

  1. Create a public repository such as retro-girly-wallpaper, or choose an existing repository you own and intend to use for this project. Do not upload personal settings exports or private notes.
  2. Upload the contents of the retro-girly folder into the repository root, keeping index.html, style.css, app.js, icons/, backgrounds/, and .nojekyll together. Do not upload only the ZIP. Include Lively JSON and guides if you want visitors to download the source for Lively.
  3. In repository Settings → Pages → Build and deployment → Source, choose Deploy from a branch. Select your branch (usually main) and /(root), then Save.
  4. Wait for GitHub’s Pages deployment to succeed. The project preview will normally be https://USERNAME.github.io/REPOSITORY/. Use the exact link shown in Settings → Pages.
  5. For an existing site with other content, put these files under a folder such as retro-girly/ in its already-published source and visit that subpath instead. Preserve its existing Pages settings.
  6. Open the resulting URL, test the calendar and Personalise controls, and check the browser console for missing files. All asset paths are relative and support project subpaths.

GitHub Pages availability depends on repository visibility and your GitHub plan. Public repositories work with GitHub Free. Pages is a website host, not the Windows wallpaper engine. You can add the published URL to Lively, but the local ZIP is the self-contained option and works without network access. Your first visit to the hosted URL needs internet; no offline service-worker cache is claimed.
